# The Legend of ZeldAAA: OcarinAAA of Time

This is a custom mod fork of the incredible PC port/decompilation project [Ship of Harkinian](https://github.com/HarbourMasters/Shipwright) designed to offer a more... ***modern*** feel to the Nintendo 64 version of the Legend of Zelda: Ocarina of Time. It's designed to be played on Windows PCs, sorry for no Mac/Linux support right now!

## Setup
OcarinAAA of Time mostly follows the [setup flow for the Windows release of Ship of Harkinian](https://www.shipofharkinian.com/setup-guide/windows).

You'll need your own, **LEGALLY** dumped copy of Ocarina of Time from your own cartridge/disk in `.z64` format. Ship of Harkinian offers guidance on how to do this [here](https://www.shipofharkinian.com/setup-guide/dump-guide). You can check your ROM's compatibility [here](https://ship.equipment/) once you've dumped it.

[You can download the latest release of the mod here.](https://github.com/null-port/OcarinAAA-of-Time/releases/latest)

Once you extract the release .zip, open `OcarinAAA.exe` you should see a prompt stating:

> **`No original-quest O2R found. Generate one now?`**

Select **`Yes`** here.

If your ROM is **not located in the same folder as the `OcarinAAA.exe`** you will have one additional prompt:

> **`No roms found. Look for one?`**

Select **`Yes`** at this prompt too and select your `.z64` file.

Otherwise, if your ROM **is located in the same folder as the `OcarinAAA.exe`**  you'll see:
> **`ROMs found in application directory. Would you like to process them?`**

Select **`Yes`** to extract the ROM it found.

Let the extraction process finish and voila! You should have a running version of this mod. Press `Esc` to trigger the settings menu if you want to adjust controls, visuals, or audio.

## Controls

By default, this mod has support for all controllers that Ship of Harkinian does. A controller with dual sticks is recommended to enjoy the free third-person camera movement.

Default XBOX controller controls map to the following:
```
N64 Controls        XInput (XBOX Controller)

Control Stick       Left Stick
Camera Look         Right Stick
A                   A
B                   B
Z                   LT
L                   LB
R                   RT
Start               Start
C-Up                D-Pad Up
C-Down              D-Pad Down
C-Left              D-Pad Left
C-Right             D-Pad Right
```

Default keyboard controls map to the following:
```
N64 Controls        Keyboard + Mouse

Control Stick       W / A / S / D
Camera Look         Mouse
A                   X
B                   C
Z                   Z
L                   E
R                   R
Start               Space
C-Up                Up Arrow
C-Down              Down Arrow
C-Left              Left Arrow
C-Right             Right Arrow
```

# FAQ

> Help! My computer can't handle it! What can I do to play the game if my computer is old? 

Try disabling "Post-processing" in the graphics settings menu. Just know you're missing out on some epic visual effects.
